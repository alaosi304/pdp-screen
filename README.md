# شاشة آراء المتدربين — دورة حماية البيانات الشخصية

إدارة تصميم تجربة التعليم · سدايا

**الرابط المباشر:** https://alaosi304.github.io/pdp-screen/

صفحة عرض تعمل تلقائيًا على شاشة Huawei IdeaHub، تعرض تعليقات المتدربين على دورة حماية البيانات الشخصية.

## طريقة العرض
- **الصف العلوي (ثابت):** التعليقات الطويلة.
- **الصف السفلي (يتبدّل):** ثلاث بطاقات تتبدّل فيها التعليقات القصيرة بالتناوب.
- إضاءة ذهبية تتنقّل بين البطاقات وتُبرز العبارات المهمة.
- زر للتبديل بين الوضع الداكن والفاتح في الزاوية اليسرى السفلية، والشاشة تتذكر الاختيار.

## إضافة تعليق جديد
1. افتح `index.html` وابحث عن `var POOL=[` (للتعليقات القصيرة) أو `var LONG=[` (للطويلة).
2. أضف سطرًا بهذا الشكل:
   ```js
   {n:"اسم المتدرب",t:"نص التعليق، و[العبارة المهمة] بين قوسين مربعين لتضيء بالذهبي."},
   ```
3. ارفع رقم الإصدار في السطر:
   ```html
   <meta name="slide-version" content="...">
   ```
4. احفظ التغيير. الشاشة تلتقط الإصدار الجديد خلال دقائق وتنتقل إليه تلقائيًا دون لمسها.

## ملاحظات تقنية
- ملف واحد مستقل، والشعار مضمّن فيه.
- مكتوب بأسلوب متوافق مع متصفح IdeaHub المدمج، وبحركة خفيفة لتجنّب البطء.
- لتشخيص أي مشكلة على الشاشة افتح الرابط مع `?debug=1`.
- لفرض الوضع: `?theme=light` أو `?theme=dark`.
